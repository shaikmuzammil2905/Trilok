# Trilok Infotech Private Limited - Official Website

Welcome to the official web application repository for **Trilok Infotech Private Limited**.

## 🌟 Features
- **Modern High-Tech Aesthetic**: Dark navy hero theme with interactive 3D HTML5 canvas globe animation and floating tech cards.
- **Scroll Reveal & Typing Counters**: Animated stat counters for 50+ Projects Delivered, 100% Client Satisfaction, Enterprise Grade Security, and Pan India Service Coverage.
- **Flagship Product Showcase**: Dedicated section for **eSaleAgreement** - India's Trusted Digital Agreement Platform with interactive feature pills and app mockup views.
- **Services & Industries**: Interactive cards for Software Development, Cybersecurity, Network Infrastructure, Cloud Solutions, AI & Automation, and tech stack badges.
- **WhatsApp Customer Lead Form**: "Get in Touch" modal that collects customer inquiry details and redirects straight to WhatsApp **+91 8639833447** with a formatted message.
- **Mobile Drawer Navigation**: Fully responsive across mobile, tablet, and desktop screens.

## 🚀 How to Run Locally
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Alternatively, run a local web server (e.g. `npx http-server .` or VS Code Live Server).
